# Nebula — Pricing Cards

A modern, responsive pricing section built with pure HTML, CSS, and JavaScript.

## Features

- Three tiers: Starter, Pro (featured), and Enterprise
- Monthly / yearly billing toggle with per-plan price animation
- Yearly billing shows a 20% discount and annual total
- Glassmorphism cards with an animated aurora background
- Fully responsive (stacks on mobile) and keyboard accessible
- Respects `prefers-reduced-motion`

## Run

Open `index.html` in any modern browser. No build step or dependencies required.
